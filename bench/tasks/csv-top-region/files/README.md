# Sales export

`sales.csv` is the 2026 export from the order system, one row per order line:

| column     | meaning                                  |
|------------|------------------------------------------|
| date       | order date (YYYY-MM-DD)                  |
| region     | sales region                             |
| product    | product name                             |
| units      | number of units sold                     |
| unit_price | price per unit in EUR                    |

# The terminal client and CLI
- `tessera`: the terminal app, a lean coding harness: one chat across the window (the most recent one in this folder, or a new one), `/split` for chats side by side. Its chats offer the coding tools only (read, write, edit, bash, job, grep, glob, task, web search); chats started in the apps keep all of theirs. `tessera run "…"`: one-shot, reads stdin when piped (also lean; `--all-tools` gives every tool).
- `tessera setup`: guided setup in four steps: the AI (finds model servers on this machine and its home network, and the user's Claude Code), where it's used (home network, remote access), the background service, pairing a phone. One step alone, any time: `tessera setup models|devices|service|pair`, plus `web`, `where` (use another server from this terminal), `security`. The installer (`curl -fsSL <repo>/releases/latest/download/install.sh | sh`, or `sh scripts/install.sh` in a copy of the source) installs Tessera first, then offers it.
- Remote access: `tessera setup devices` offers an automatic Cloudflare Tunnel (needs a domain on Cloudflare), Tailscale (free, no domain) or the user's own proxy; it waits for the tunnel to connect and names the fix when outbound port 7844 is blocked. Walking the user through it: `docs remote-access`.
- Claude in setup: the user's Pro/Max plan through their own Claude Code (installed and signed in with `claude`; Tessera never handles that login), or an Anthropic API key.
- `tessera serve [--bind 0.0.0.0:7878]`: run the server. `tessera service install|status|uninstall`: run it in the background (systemd).
- `tessera pair`: one-time code and QR to pair a phone, the desktop app or another terminal, plus a private link to paste on a computer without a camera (`c` copies it). The code carries the remote address and any Access headers. `tessera devices [--revoke ID | --rename ID --name NAME]` (one block per computer).
- `tessera remote <urls> -H Name=Value`: addresses and headers devices use from elsewhere. `tessera connect <url|link> --code …`: use a remote server from this terminal.
- `tessera node enable|disable|status|scope|name|service|log|run`: this computer as a machine for the user's server (only ever run by the user on that computer; see `docs machines`).
- `tessera providers`, `tessera add-provider`, `tessera model provider/model`, `tessera login chatgpt`, `tessera web searxng <url>`.
- `tessera doctor`: paths and configuration status.
In the terminal app: `/` lists the commands (`/new`, `/chats`, `/split`, `/close`, `/model`, `/thinking`, `/compact`, `/rewind`, `/goal`, `/copy`, `/settings`, `/help`, `/quit`), `?` shows the keys. `/settings` (F2): permissions, the model for new chats, showing the thinking, the theme (`auto` keeps the terminal's colours; `dark`, `light`, `contrast`, `catppuccin`, `gruvbox`, `tokyo-night`; `TESSERA_THEME=<name>` for a single run; `NO_COLOR` turns colour off), the mouse. Bots, notes, whiteboards and the rest of Tessera are in the apps.
